## Per-app legal pages

App-specific Privacy Policy and Terms of Service pages are generated by
`lib/legal-apps.ts`. The API only needs a small payload; the server generates
all legal URLs and both legal documents automatically. Each app publishes:

- `/{slug}` — legal center
- `/{slug}/privacy` — custom Privacy Policy
- `/{slug}/terms` — custom Terms of Service

### Create an app through the API

Configure the server:

```env
LEGAL_APPS_API_KEY=replace-with-a-secret
LEGAL_SITE_URL=https://policy.nextteam.site
```

Create `payload.json`:

```json
{
  "name": "Example App",
  "slug": "example-app",
  "contact_email": "support@example.com",
  "description": "A short description of the app.",
  "icon_url": "https://example.com/app-icon.png",
  "store_url": "https://play.google.com/store/apps/details?id=com.example.app",
  "accent_color": "#7c3aed"
}
```

The server derives `/example-app`, `/example-app/privacy`,
`/example-app/terms`, CCPA, and copyright URLs from `slug` and
`LEGAL_SITE_URL`.

Using an icon URL from the JSON:

```bash
curl -X POST https://policy.nextteam.site/api/legal-apps \
  -H "Authorization: Bearer $LEGAL_APPS_API_KEY" \
  -H "Content-Type: application/json" \
  --data @payload.json
```

Uploading a local icon instead of sending `icon_url`:

```bash
curl -X POST https://policy.nextteam.site/api/legal-apps \
  -H "Authorization: Bearer $LEGAL_APPS_API_KEY" \
  -F 'payload=<payload.json' \
  -F 'icon=@/path/to/app-icon.png'
```

Or use the included generator script:

```bash
LEGAL_API_URL=https://policy.nextteam.site/api/legal-apps \
LEGAL_APPS_API_KEY=your-secret \
npm run legal:create -- payload.json /path/to/app-icon.png
```

Uploaded icons may be PNG, JPEG, WebP, GIF, or AVIF and are limited to 2 MB.
The API stores runtime-created apps in `data/legal-apps.json`; the new legal
URLs are available immediately without rebuilding. This file-backed storage is
intended for a persistent Node/VPS deployment. Use database or object storage
instead when deploying on a serverless platform such as Vercel.
